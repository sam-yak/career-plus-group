# Career Plus Group — project context

Static, lead-generation website for Career Plus Group: an Indian advisory group
operating under Career Plus Educational Society, with two divisions and five
business lines. Built with Astro, deployed to GitHub Pages.

Working solo: the owner's son, in-house developer, learning the business as he
builds. Prefer explaining a trade-off over silently picking one.

---

## The governing principle — read this before changing any page

Career Plus will keep adding business lines. The site is built as **one vertical
template plus a data file**, not as a collection of pages.

**`src/data/verticals.ts` is the source of truth.** All five business lines are
objects in one array. `src/pages/[slug].astro` reads that array and generates
seven pages: two division hubs and five vertical landing pages.

### Hard rules

- **Never create a page file for an individual vertical.** No `real-estate.astro`,
  no `loans.astro`. If a vertical needs something the template lacks, add an
  optional field to the `Vertical` interface and render it conditionally in
  `VerticalPage.astro` so every vertical can use it.
- **Never duplicate the enquiry form.** `EnquiryForm.astro` is one component with
  conditional field groups keyed on `data-group`. A new vertical adds one
  `<option>` and one fieldset — never a second form component.
- **The extensibility test:** before merging any change, ask *"if we add a sixth
  vertical tomorrow, does this need a developer?"* If yes, restructure it.
- **Internal links must go through `url()`** from `src/lib/url.ts`. A bare
  `href="/loans"` breaks on GitHub Pages, which serves from a `/career-plus-group`
  sub-path. This is the single most common way to break the deployed site.

If a request would violate one of these, say so and propose the alternative
rather than complying quietly.

## Structure

```
src/data/site.ts          Group identity, contact, divisions, partners, trust stats
src/data/verticals.ts     ← ALL BUSINESS LINES. The important file.
src/pages/[slug].astro    Generates division hubs + vertical pages
src/pages/index.astro     Homepage
src/components/
  VerticalPage.astro      The 8-block vertical template
  EnquiryForm.astro       One form, five conditional field groups
  Header.astro            Sticky header, two-division mega-menu
src/lib/url.ts            Base-path-safe link helper
src/styles/global.css     All styling. No CSS framework, no utility classes.
```

### The vertical template — 8 blocks, fixed order

1. Hero · 2. Who it's for · 3. How it works · 4. What we offer
5. Requirements · 6. Why Career Plus · 7. FAQ · 8. Enquiry form

Blocks 1, 3, 6, 7, 8 are mandatory. Blocks 2, 4, 5 collapse automatically when a
vertical has no data for them. Do not reorder these — the sequence is a
conversion decision, not an aesthetic one.

## Design system

Derived from the client's two existing division logos. Do not introduce new
colours or typefaces without asking.

| Token | Value | Use |
|---|---|---|
| Navy | `#1A2A4F` | Headings, nav, footer, dark bands |
| Gold | `#C08B3E` | CTAs, eyebrows, accents |
| Ink | `#23231F` | Body text |
| Sand | `#F6F4EF` | Alternating section backgrounds |

- Display type: **Cinzel** (matches the inscriptional serif in the logos), H1–H3 only.
- Body type: **Source Sans 3**.
- Signature device: the `R·01` / `H·02` notation — division code plus position
  within that division. Generated by `notation()` in `verticals.ts`. It encodes
  real structure; don't replace it with generic numbering.
- Sentence case everywhere. No emoji anywhere in the UI.
- Mobile-first — assume 70%+ of traffic is mobile.

## Business context that constrains the copy

Career Plus is an **intermediary in all five verticals**. It owns no inventory:
not the properties, not the money, not the water, not the universities, not the
flights. It connects customers to partners and earns commission. This is why
there is no cart, no checkout and no booking engine anywhere on the site.

Two compliance guardrails that must never be relaxed:

1. **Loans.** Career Plus is a facilitator (a DSA), not a lender — lending
   requires an RBI licence. Copy must never say "we offer loans", "we approve",
   or imply guaranteed approval. Use "we arrange", "through our partner banks",
   "subject to lender approval".
2. **Alkaline water.** No health or medical claims. Sell on taste, guest
   experience and branding only.

Anything unverified is marked `TODO(client)` in `site.ts` or shown with a
`.pending` badge in the UI. Do not invent placeholder statistics, partner names,
registration numbers or testimonials to fill these — an obvious gap is better
than a plausible fabrication that reaches a live site.

## Commands

```bash
npm run dev      # localhost:4321/career-plus-group

```

Always run `npm run build` before committing. Broken base paths and Astro type
errors surface at build time, not in dev.

## Deployment

Push to `main` → GitHub Action → GitHub Pages. `base` in `astro.config.mjs` must
equal the repository name. On the real domain, set `base: '/'` and add
`public/CNAME`.

The enquiry form has **no backend yet**. It validates, then logs to console and
shows a confirmation — see the block marked `DEMO MODE` in `EnquiryForm.astro`.
Wiring it to Formspree, Netlify Forms or a real endpoint is the next task.
